# Roadmap

What might come next. Nothing here has a date. If you want one of these, say so in an issue, or help build it ([CONTRIBUTING.md](../CONTRIBUTING.md)).

## Wanted

- **Outlook.com, Hotmail and Microsoft 365**, through Microsoft's own sign-in (OAuth).
- **Proton Mail** through Proton Bridge (needs support for its local, self-signed certificate).
- **Gmail without app passwords**, through Google's own sign-in.
- **HTML signatures on hosting companies** without a terminal (asking the AI sets a simple one).
- **A one-click Railway template**, so option 2 needs no fork.
- **A ready-made Docker image** on GitHub's container registry, so option 3 needs no build.
- **A Claude Desktop extension** (`.mcpb` file) for a double-click install.

## Maybe

- **Alias add-on:** create, list and turn off SimpleLogin and addy.io aliases, and write to someone new from an alias.
- A daily summary email of what the AI did.
- Ready-made prompts in AI apps that support them ("triage my inbox", "summarise this thread").

## Not planned

- **A hosted service run by us.** This project is for running your own copy; holding other people's mail passwords is a responsibility we don't want to take on.
- **Permanent deletion.** The AI can move emails to Trash, never delete them for good.
- **Calendars.** Other tools do this well.
